<h1 align="center">💼Portfólio E.M.B</h1>

<h2 align="left">📌 Objetivo:</h2>

###

<p align="left">Ajudar pequenos negócios e profissionais autônomos a terem presença digital profissional, aumentando credibilidade e geração de clientes.</p>

###

<h2 align="left">💡 Sobre o projeto:</h2>

###

<p align="left">O Portfólio E.M.B foi criado para atender um cliente real da área de automação de portões e segurança eletrônica.<br><br>O projeto começou como uma landing page simples e evoluiu para uma plataforma web completa, com múltiplas páginas, funcionalidades dinâmicas e integração com backend.<br><br>O objetivo principal é apresentar serviços, facilitar contato com clientes e transmitir profissionalismo no ambiente digital.</p>
